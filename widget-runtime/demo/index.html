Pretend customer website

This page carries nothing but the embed snippet — exactly what a customer pastes in. Everything else you see comes from the widget.

What to try

  1. Click the bubble in the corner.
  2. Fill in the identification form — try submitting it empty first to see validation.
  3. Send a message. A mock agent replies after ~2.5 seconds.
  4. After that reply the marketing opt-in appears (this config uses after_first_response).
  5. Close the panel to trigger the feedback form.

Check what the backend received

Open /__state to see the captured conversation, messages, opt-in and feedback — the local stand-in for querying ServiceConversations.
